Roof + Space

Walls, rooms and hip or gable roofs share this drawing's units and Undo history. Ceiling height and roof bearing height are separate controls.

Wall properties

Select one horizontal LINE, polyline or rectangle before opening Architecture. Left and right refer to the path direction; no exterior face is guessed. Source drafting geometry is retained.

New straight wall / partition

Exact building-local XY coordinates, using the drawing's length parser. Choose Nonbearing partition for interior partitions.

Shared junction

Opening in selected wall

Openings belong to the selected wall and preserve room enclosure. Distances run from that wall's start junction.

Driving span

Set a signed X or Y span. The connected perpendicular wall chain moves as one source edit; conflicting constraints are diagnosed.

Synthetic footprint starters

Adds only a closed source polyline at the building-frame origin. Roof vertices are generated later. Assign physical drawing units first.

Recognize enclosed regions

Recognizes bounded rooms from shared wall topology. Hosted door/window openings do not cut the enclosure. Create or edit walls first.

Ceiling intent

Accepted ceiling intent is stored independently from roof bearing and eave elevations. Space study calculates mathematical clearance, flat and rectangular tray volumes and headroom area beneath a fixed roof.

Use Space study with zero-thickness surfaces, inspect the limiting obstruction, apply a feasible flat or tray ceiling, or create a dimensioned section. Roof and ceiling thickness and reservation boxes can be added anytime. One rectangular tray is available. Vaults remain later work; roof bearing elevations are edited separately in Roof.

Draft terminal gable assignments

Select terminal edge chains using building-local endpoints. Suggestions only change this draft. Confirm assignments before generating or applying the roof.

Draft geometry check

The draft check runs the same bounded support and roof validation without changing the drawing or Undo history. Confirm edited edge pitches, bearing elevations and gable drafts, then Apply to accept one grouped edit.

Accepted generation status

A selected drafting path is captured as architectural source; later edits to it do not edit the roof. Wall-perimeter coverage stays linked to semantic wall junctions. One simple orthogonal footprint with open recesses is supported. Gable ends are explicit terminal assignments; unresolved or incompatible selections report diagnostics. Per-edge bearing heights use delayed source fronts. Unsupported contacts and consumed supports reject the edit; no partial roof is accepted.

Eave overhang offsets sloping-eave edges; rake overhang offsets assigned gable ends. The mathematical roof, vertical gable closures and roof-to-support step closures have zero thickness. Ceiling elevation remains independent of bearing.

For rotated buildings, enter exact building-local wall coordinates. Converting a rotated drafting path can leave numerical deviations that the strict orthogonal roof solver rejects.

Material and framing assumptions

Prefabricated-truss design/manufacturing complexity surcharge: 0. Surface and edge quantities remain physical quantities. Truss webs, lumber, connectors, assembly clearances and structural feasibility remain unverified until explicitly modeled and reviewed.

Study a finished flat ceiling or one rectangular tray beneath the accepted, fixed roof. Proposals stay separate from the accepted ceiling until explicitly applied. Roof pitch, bearing, overhang and exterior vertices remain fixed. This mathematical model uses zero-thickness surfaces by default. Optional thickness and reservation boxes can be added anytime.

Room and fixed roof

Optional thickness and reservations

Rectangular tray proposal

Enter building-local plateau bounds strictly inside the room. The lower outer band and raised plateau are finished underside elevations. Vertical returns are mathematical surfaces with zero thickness and zero material volume.

Dimensioned section

Creates ordinary section geometry and measured labels as one Undo group. The current profile follows the accepted flat or tray ceiling. Unaccepted tray proposals are not drawn as the current profile. Sections are snapshots; generate a new section after changing source.

Calculated usable space

Ceiling elevation is the finished underside. Clear height is measured above the room floor. Roof layers reduce clearance by normal thickness; ceiling finish extends vertically above the finished ceiling. Both thicknesses default to zero. Local XYZ reservations include their entire entered box. Both truss design and manufacturing complexity surcharges remain 0.

Bounded reservation boxes

Coordinates use the building-local frame and the drawing's architectural length parser. Positive-volume boxes are required. Saving a reservation requires an explicitly declared roof assembly.

Bounded material and ceiling-space alternatives

Search a stated grid, inspect measured quantities, then review one feasible configuration before accepting one grouped edit. The search uses a source snapshot and does not edit the drawing. A complete search describes this grid only; it does not establish a global optimum.

Separate choices with semicolons, for example 8'; 9'; 9' 6". Elevations use the building datum. Listed trays use the current lower ceiling elevation; maximum-fit search also checks a fitted lower base. Each tray uses one equal inset from the selected room's bounding rectangle. Unsupported or infeasible trays remain rejected evidence rows.

Explicit co-design permissions

Pitch choices use semicolons, for example 4; 4.5; 6. Offsets use drawing lengths and move every selected roof bearing and its linked support-wall tops equally. Coverage and gable assignments stay fixed. Shared supports, locked heights and unresolved constraints reject a configuration.

    Run the supplied Python adapter manually with the exported request and an explicit external engine folder. Python 3.10+ and that engine are needed only for this optional calculation; CAD and JSON export work independently. Then import the result here.
    python linecraft-structural-adapter.py --engine-root ENGINE_FOLDER --request REQUEST.json --output RESULT.json
    Nothing in this dialog executes engine code. Imported engine identity is an external declaration. Source binding and declared factor arithmetic are checked; code compliance, framing, connections and member capacities remain unverified.

    Spatial boundary checks
